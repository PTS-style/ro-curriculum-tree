## 🌟 ฟีเจอร์หลัก (Key Features)

### 1. ธีมและบรรยากาศ Ragnarok Online (RO Classic Aesthetic)
- กรอบหน้าต่าง RO Window สไตล์ 3D Bevel พร้อมหัวข้อไล่เฉดสีคลาสสิก
- เสียงเอฟเฟกต์สังเคราะห์ (RO Retro Sound Chimes) ด้วย Web Audio API ไม่ต้องต่อเน็ต
- ปุ่มสลับเปิด/ปิดเสียง 🔊 / 🔇
- แถบเมนูด้านซ้ายสไตล์ RO Job Selector:
  - 🏛️ **1. GE (หมวดวิชาศึกษาทั่วไป)**
  - ⚔️ **2. วิชาหลักสูตร (วิชาเฉพาะ/วิชาแกน)** *(เปิดเป็นหน้าแรกตามค่าตั้งต้น)*

### 2. ผังรายวิชา 3 คอลัมน์ (3-Column Skill Level System)
- แบ่งระดับวิชาเป็น 3 คอลัมน์ชัดเจน:
  - **Column 1 (ระดับ 1 - Foundation):** วิชาพื้นฐาน (ปี 1 - 2) เช่น CCNA 1, HCCDA
  - **Column 2 (ระดับ 2 - Intermediate):** วิชาปฏิบัติการ (ปี 2 - 3) เช่น CCNP, HCCDP
  - **Column 3 (ระดับ 3 - Advanced):** วิชาขั้นสูงและโปรเจกต์ (ปี 3 - 4) เช่น CCIE, HCCDE
- สามารถลากกล่องวิชาข้ามไปมาระหว่างคอลัมน์ได้อย่างอิสระ โดยระบบจะตรวจจับระดับ Level ให้อัตโนมัติ

### 3. กล่องรายวิชา (Node Box สไตล์ n8n) & จุดเชื่อมต่อ 4 ทิศทาง
- แต่ละกล่องมี **จุดเชื่อมต่อ 4 จุด: บน (Top), ล่าง (Bottom), ซ้าย (Left), ขวา (Right)**
- สามารถลากเชื่อมโยงข้ามทิศทางใดก็ได้ตามต้องการ
- **พิมพ์เปลี่ยนชื่อได้ทันที (Inline Editing):** คลิกที่รหัสวิชาหรือชื่อวิชาแล้วพิมพ์แก้ไขได้ทันที
- **เมนูคลิกขวา (Context Menu):** แถบสี Palette สำหรับเปลี่ยนสีสายวิชา (แดง: Network, ฟ้า: Cloud, ม่วง: IoT, เขียว: Software, ส้ม: Data & AI, เทา: CyberSec ฯลฯ)

### 4. แถบตั้งค่าเส้นและทิศทางลูกศร (Right Line Inspector Panel)
เมื่อลากสร้างเส้นเชื่อม หรือคลิกที่เส้นเชื่อมใดๆ บนผัง:
- แถบเครื่องมือทางขวาจะเปิดขึ้นเพื่อตั้งค่าเส้นทันที:
  1. **เลือกรูปแบบเส้น (Line Type):**
     - 🔵 **เส้นทึบสีฟ้า:** วิชาบังคับก่อนโดยตรง (AND Logic) — ต้องผ่านวิชาต้นทางก่อนเท่านั้น (หากมีหลายเส้นชี้เข้า ต้องผ่านทุกวิชา)
     - 🟠 **เส้นประสีส้ม:** คำแนะนำว่าควรเรียนต่อ (Advisory / Recommended) — แนะนำตามหลักสูตร ไม่ได้บังคับในระบบทะเบียน
     - 🟢 **เส้นทึบสีเขียว:** วิชาเลือกบังคับก่อน (OR Logic) — หากมีหลายเส้นชี้เข้า สามารถเลือกผ่านวิชาใดวิชาหนึ่งได้
  2. **กำหนดตำแหน่งลูกศร (Arrow Direction):**
     - ➔ **ชี้ไปข้างหน้า (A ➔ B):** ลูกศรชี้เข้า B หมายถึง ต้องเรียน A ก่อนไป B
     - ⬅️ **สลับทิศทาง (A ⬅️ B):** ลูกศรชี้เข้า A หมายถึง ต้องเรียน B ก่อนไป A
     - ⟷ **สองทิศทาง (A ⟷ B):** วิชาสัมพันธ์ร่วมกัน
  3. **คำอธิบายความหมายของเส้น:** แสดงสรุปความหมายตามเงื่อนไขของหลักสูตรแบบเรียลไทม์
  4. **ปุ่มลบเส้น:** ลบเส้นความสัมพันธ์ได้ทันทีจากแถบด้านขวา

## 🖨️ การพิมพ์และส่งออกเอกสาร (Print & Export)

- **ปุ่ม 🖨️ สั่งพิมพ์ / PDF:** จัดหน้าแบบฟอร์ม A4 แนวนอน (Landscape) อัตโนมัติ ซ่อนแถบเครื่องมือและเมนู เหลือเฉพาะหัวเรื่องหลักสูตร, แผนผัง 3 ระดับ, กล่องรายวิชา และคำอธิบายสัญลักษณ์เส้น
- **ปุ่ม 💾 บันทึกไฟล์ (Save JSON):** บันทึกโครงสร้างหลักสูตรเป็นไฟล์ `.json` เพื่อนำไปเปิดในเครื่องอื่น
- **ปุ่ม 📂 โหลดไฟล์ (Load JSON):** โหลดไฟล์หลักสูตรเดิมกลับมาแก้ไขต่อได้ตลอดเวลา
- **ปุ่ม 🔄 คืนค่าตัวอย่าง:** โหลดตัวอย่างสาย Network และสาย Cloud พร้อมตัวอย่างเส้นทั้ง 3 แบบ
