## 🌟 ฟีเจอร์หลัก (Key Features)

### 1. ธีมและบรรยากาศ Ragnarok Online (RO Classic Aesthetic)
- กรอบหน้าต่าง RO Window สไตล์ 3D Bevel พร้อมหัวข้อไล่เฉดสีคลาสสิก
- เสียงเอฟเฟกต์สังเคราะห์ (RO Retro Sound Chimes) ด้วย Web Audio API ไม่ต้องต่อเน็ต
- ปุ่มสลับเปิด/ปิดเสียง 🔊 / 🔇
- แถบเมนูด้านซ้ายสไตล์ RO Job Selector:
  - 🏛️ **1. GE (หมวดวิชาศึกษาทั่วไป)**
  - ⚔️ **2. วิชาหลักสูตร (วิชาเฉพาะ/วิชาแกน)** *(เปิดเป็นหน้าแรกตามค่าตั้งต้น)*

### 2. ผังรายวิชา 3 คอลัมน์ (3-Column Skill Level System)
- แบ่งระดับวิชาเป็น 3 คอลัมน์ชัดเจน:
  - **Column 1 (ระดับ 1 - Foundation):** วิชาพื้นฐาน (ปี 1 - 2) เช่น CCNA 1, HCCDA
  - **Column 2 (ระดับ 2 - Intermediate):** วิชาปฏิบัติการ (ปี 2 - 3) เช่น CCNP, HCCDP
  - **Column 3 (ระดับ 3 - Advanced):** วิชาขั้นสูงและโปรเจกต์ (ปี 3 - 4) เช่น CCIE, HCCDE
- สามารถลากกล่องวิชาข้ามไปมาระหว่างคอลัมน์ได้อย่างอิสระ โดยระบบจะตรวจจับระดับ Level ให้อัตโนมัติ

### 3. กล่องรายวิชา (Node Box สไตล์ n8n)
- แสดงรหัสวิชา, หน่วยกิต, ชื่อวิชาภาษาไทย, ชื่อวิชาภาษาอังกฤษ, และแถบสีประจำสายวิชา
- **พิมพ์เปลี่ยนชื่อได้ทันที (Inline Editing):** คลิกที่รหัสวิชาหรือชื่อวิชาแล้วพิมพ์แก้ไขได้ทันทีโดยไม่ต้องเปิดหน้าต่างใหม่
- **เมนูคลิกขวา (Context Menu):**
  - แถบสี Palette ให้เลือกสีสายวิชาได้ทันที:
    - 🔴 **Network:** สีแดง
    - 🔵 **Cloud:** สีฟ้า
    - 🟣 **IoT / Embedded:** สีม่วง
    - 🟢 **Software Dev:** สีเขียว
    - 🟠 **Data & AI:** สีส้ม
    - 🟡 **Cybersecurity:** สีเทาเข้ม
    - 🌸 **Design:** สีชมพู
    - 🐬 **DevOps:** สีมิ้นท์
  - ดับเบิลคลิกเพื่อเปิดหน้าต่างแก้ไขข้อมูลละเอียด (Code, Credits, Thai/English name, Color)
  - คัดลอกรายวิชา (Duplicate) หรือลบรายวิชา (Delete)

### 4. ระบบจุดเชื่อมต่อ 6 จุด & เส้นความสัมพันธ์ 3 รูปแบบ
แต่ละกล่องรายวิชามีจุดเชื่อมต่อ 6 จุด (ฝั่งซ้าย 3 จุดเป็นขาเข้า In, ฝั่งขวา 3 จุดเป็นขาออก Out):
1. 🔵 **เส้นทึบสีฟ้า (จุดบน):** **วิชาบังคับก่อนโดยตรง (Hard Prerequisite: AND Logic)**
   - ต้องสอบผ่านวิชา A ก่อนเท่านั้นจึงจะลงเรียนวิชา B ได้
   - หากวิชา B มีเส้นสีฟ้าเข้าทางซ้ายหลายเส้น หมายความว่าต้องสอบผ่านให้ครบทุกสาย
2. 🟠 **เส้นประสีส้ม (จุดกลาง):** **คำแนะนำว่าควรเรียนต่อ (Advisory / Recommended)**
   - เป็นคำแนะนำของผู้ออกแบบหลักสูตร แต่ไม่ได้มีกฎข้อบังคับของสำนักทะเบียน
3. 🟢 **เส้นทึบสีเขียว (จุดล่าง):** **วิชาเลือกบังคับก่อน (Elective Prerequisite: OR Logic)**
   - หากมีวิชา A, B, C เชื่อมเส้นสีเขียวเข้าวิชา D หมายความว่าเลือกเรียนผ่านตัวใดตัวหนึ่งก็สามารถลง D ได้
   - สามารถใช้ผสมกับเส้นสีส้มและสีฟ้าได้ตามเงื่อนไขหลักสูตร

## 🖨️ การพิมพ์และส่งออกเอกสาร (Print & Export)

- **ปุ่ม 🖨️ สั่งพิมพ์ / PDF:** จัดหน้าแบบฟอร์ม A4 แนวนอน (Landscape) อัตโนมัติ ซ่อนแถบเครื่องมือและเมนู เหลือเฉพาะหัวเรื่องหลักสูตร, แผนผัง 3 ระดับ, กล่องรายวิชา และคำอธิบายสัญลักษณ์เส้น
- **ปุ่ม 💾 บันทึกไฟล์ (Save JSON):** บันทึกโครงสร้างหลักสูตรเป็นไฟล์ `.json` เพื่อนำไปเปิดในเครื่องอื่น
- **ปุ่ม 📂 โหลดไฟล์ (Load JSON):** โหลดไฟล์หลักสูตรเดิมกลับมาแก้ไขต่อได้ตลอดเวลา
- **ปุ่ม 🔄 คืนค่าตัวอย่าง:** โหลดตัวอย่างสาย Network (CCNA > CCNP > CCIE) และสาย Cloud (HCCDA > HCCDP > HCCDE) พร้อมตัวอย่างเส้นทั้ง 3 แบบ

## 🚀 วิธีการใช้งาน & ติดตั้งบน GitHub Pages

1. นำไฟล์ `index.html` ไปวางบน Repository บน GitHub
2. ไปที่ **Settings -> Pages** เลือก Branch: `main` / `master` แล้วกด Save
3. ใช้งานผ่าน URL ของ GitHub Pages ได้ทันที หรือเปิดไฟล์ `index.html` บนบราวเซอร์ใดก็ได้แบบ Offline 100%
